Open it in Android Studio

  1. Clone or download the GitHub repository. Open its ForkAndFind subfolder containing settings.gradle.kts.
  2. Use Android Studio Meerkat or a newer compatible release, with JDK 17 and Android SDK Platform 35.
  3. Let Gradle sync download dependencies. The initial setup needs internet access.
  4. Select an Android 8.0 / API 26 or newer emulator or connected device, then run the app configuration.

Build & verify

From the Android project folder on Windows:

gradlew.bat assembleDebug testDebugUnitTest lintDebug

macOS/Linux: use sh gradlew with the same tasks. Debug APK: app/build/outputs/apk/debug/app-debug.apk.

Search unit tests are included. Compilation, lint, and emulator verification were not completed in the creation environment.

Small, approachable codebase

MainActivity.kt contains the Compose interface. Restaurant.kt provides the sample catalog and search logic. SharedPreferences stores favorites locally.
